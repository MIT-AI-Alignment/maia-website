# Contrast reference

These pairings meet WCAG AA for normal-size text unless noted otherwise.

| Pair | Ratio | Use |
| --- | ---: | --- |
| `#191522` on `#F5F3EF` | 16.17:1 | Light-theme primary text |
| `#736B7E` on `#F5F3EF` | 4.58:1 | Light-theme muted text |
| `#6B43B8` on `#F5F3EF` | 6.07:1 | Light-theme links and actions |
| `#FFFFFF` on `#6B43B8` | 6.73:1 | Light-theme solid actions |
| `#F7F3FA` on `#1D1427` | 16.21:1 | Dark-theme primary text |
| `#B8AFC4` on `#1D1427` | 8.44:1 | Dark-theme muted text |
| `#9A70D6` on `#1D1427` | 4.79:1 | Dark-theme links and icons |
| `#FFFFFF` on `#7954B6` | 5.59:1 | Dark-theme solid actions and feature panels |

Do not use white body text on `#9A70D6`; its contrast is only 3.71:1. Use `#7954B6` for dark-theme surfaces that need white text.
